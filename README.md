# IPA Сейф — установщики и обновления

Здесь публикуются готовые установщики macOS, описания версий и подписанный каталог
обновлений. Исходный код приложения хранится отдельно в закрытом репозитории.

## Установка

1. Откройте [последний выпуск](https://github.com/semen9559-debug/ipasafe-updates/releases/latest).
2. Скачайте файл `.dmg`, откройте его и перетащите «IPA Сейф» в «Программы».
3. Запускайте приложение из «Программ».

Требуется macOS 14 Sonoma или новее. Один установщик поддерживает Mac с Intel
и Apple Silicon. Homebrew, Xcode и Terminal для работы не нужны.

У приложения пока нет Developer ID и нотарификации Apple. Если macOS заблокировала
первый запуск, после попытки открыть приложение используйте «Системные настройки» →
«Конфиденциальность и безопасность» → «Всё равно открыть». На управляемом Mac это
может запретить администратор. Отключать защиту системы не требуется.

## Обновление

Начиная с 0.3.0 доступны пункт «IPA Сейф» → «Проверить обновления…» и ссылка
в боковой панели. Автоматическую проверку можно включить флажком.
Приложение проверяет криптографические подписи каталога и пакета перед установкой.
С версии 0.2.1 и старше первый переход нужно выполнить вручную из DMG.

Библиотека IPA и сессия Apple Account хранятся отдельно от приложения.
Установщик не содержит аккаунтов или архивов пользователей. Вход выполняется
в собственный Apple Account в приложении. Доступность IPA определяется Apple.

Лицензии и соответствующие исходники внешних компонентов включены в .app:
Contents/Resources/Licenses и Contents/Resources/SourceArchives.

`appcast.xml` подписан. Ручное редактирование без повторной подписи запрещает
клиентам использовать каталог. Файлы опубликованных версий не перезаписываются.
